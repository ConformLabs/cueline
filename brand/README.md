# Cueline logo

The mark is the C of Cueline drawn as four caption lines: two full lines at the top and bottom, two short lines on the left. It opens on the right like the Conform Labs C, and the anchor square sits in the opening, where the next word lands.

Every file here is generated by `build.py` from the geometry on the 200 grid and Space Grotesk (`fonts/`). Change the script, not the files.

| File | Use |
|---|---|
| `cueline-mark.svg` | the mark on light backgrounds (ink lines, blue anchor) |
| `cueline-mark-reversed.svg` | the mark on dark backgrounds (ivory lines, light blue anchor) |
| `cueline-mark-mono.svg` | one colour (print, stamps) |
| `cueline-icon.svg` | app icon, 128 px and up |
| `cueline-icon-small.svg` | app icon, 32–64 px (heavier lines, solid anchor) |
| `cueline-icon-16.svg` | app icon, 16 px |
| `cueline-tile.svg` | the C on the blue tile, as the Premiere Pro panel draws it in its header; for installers |
| `cueline-lockup.svg`, `-reversed.svg` | mark + "Cueline Captions" + "for Adobe® Premiere Pro®" |
| `cueline-lockup-endorsed.svg`, `-reversed.svg` | the lockup with "A CONFORM LABS PRODUCT", for installers, README headers and the site |
| `cueline-wordmark.svg`, `-reversed.svg` | the word alone, where the mark is already nearby |
| `png/icon-<size>.png` | app icon PNGs, 16–1024 px, each size from the form drawn for it |
| `png/icon-<size>.png` | app icon PNGs, 16–1024 px (including 400, as Surehand's) |
| `png/mark-*.png`, `png/lockup-*.png`, `png/tile-256.png` | PNG copies for places that can't take SVG |

**Sizes match Surehand's** so the two products' headers line up: the lockup is 520×104 (PNG 1040×208, shown 520 wide
in the README); its mark's ink is 57.5 tall from y 23, the name 34 tall on a baseline at 55.5 from x 115.5: "Cueline" in Space
Grotesk 600 and, 16.5 after it, "Captions" in Space Grotesk 500 (`#5B5A55` / `#A9A79F`), as "Surehand" and "MCP"
(tracking −0.044), the "for Adobe®…" line 12 tall on a baseline at 83.5 from x 114 (Space Grotesk 600,
tracking −0.033, `#4A4944` / `#C9C6BD`). The product is called Cueline; the logo says "Cueline Captions" (the installers' sidebar too: installer/app.json
`wordmark`). Marks are 220×220, icons and the tile 200×200. `build.py` has the numbers.
| `Cueline.icns` | macOS icon |
| `Cueline.ico` | Windows icon (16–256 px) |

`build.py` also writes the panel's menu icons to `../extension/img/panel-icon.png` and `panel-icon@2x.png`.

Colours: ink `#14161A`, ivory `#F2EFE8`, Cueline blue `#6EA8FF` (on dark) and `#1F5BBF` (on light). The blue passes 4.9:1 or more as text on every Conform Labs paper token in its theme. Cueline never uses the lab's tally orange.
Wordmark: Space Grotesk 600 ("Cueline"), sub-line and endorsement at 500, all outlined.

Clear space: the anchor square's width times two (48 on the 200 grid) on every side. Minimum size: 24 px for the full mark; below 48 px use the small icon forms.

The name "Premiere Pro" is never part of the logo itself: Adobe and Premiere Pro are trademarks of Adobe. It appears only in the sub-line, with ®.

To rebuild: `pip install cairosvg fonttools brotli pillow`, then `python3 build.py` (macOS, for `iconutil`).
