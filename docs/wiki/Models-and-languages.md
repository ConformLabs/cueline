# Models and languages

**☰ › Models** downloads, lists and removes speech models.

| Model | Size | Best for |
|---|---|---|
| ivrit.ai large-v3-turbo | 1.6 GB | Hebrew, fast (recommended for Hebrew) |
| ivrit.ai large-v3 | 3.1 GB | Hebrew, slower, fewer errors on names |
| Whisper large-v3-turbo | 1.6 GB | 99 languages, fast |
| Whisper large-v3 | 3.1 GB | 99 languages, most accurate |
| Whisper small | 0.5 GB | 99 languages, quick drafts |

Picking a language the current model doesn't cover switches to a multilingual one you have.

**Language:** type to search Whisper's 100 languages, by English name, own name ("עברית") or code ("he"), or choose
**Auto detect**. **Translate to English** gives English captions from any spoken language.

**Skip silence** (on by default) uses a small silence model (Silero VAD, 1 MB, downloaded once): faster, and no
invented words in quiet parts.
