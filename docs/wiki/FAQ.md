# FAQ

**Does Cueline upload my audio?**
No. Transcription and speaker detection run on your computer. See [Settings and files](Settings-and-files#network).

**Which languages?**
Hebrew with ivrit.ai's models, and the 99 others Whisper knows. See [Models and languages](Models-and-languages).

**Why does Update timeline add a new caption track?**
Premiere Pro's scripting can create caption tracks but not change or delete them.

**Can it style captions (font, colour, position)?**
Not from the panel: use Premiere Pro's Track Style on each caption track. With a caption track per speaker, each
speaker can have their own.

**Does it work offline?**
Yes, once the models are downloaded.

**Mac or Windows?**
Both. On a Mac, transcription uses the GPU; on Windows, the CPU.
