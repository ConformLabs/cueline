# Upgrading

Cueline looks for a new version once a day (on GitHub, nothing else is sent). When there is one, the panel's footer
says **update ready**, and **☰ › Updates** shows what's new.

1. Click **Download** on the Updates screen (or get it from [Releases](https://github.com/ConformLabs/cueline/releases)).
2. Run the installer, as in [Installing](Installing). It replaces the panel; your models, settings and history are kept.
3. Restart Premiere Pro.

To stop the daily check: **☰ › Updates › Check automatically › off**. **Check now** still works.
